Privacy Policy

Last updated: 17 November 2026

"Luke Cassar Posting Tool" is a private tool used by one person, Luke Cassar (@lukebcassar), to upload his own videos to his own TikTok account. It is not offered to the public and has no other users.

What the tool accesses

With Luke's permission, the tool uses TikTok's Content Posting API to upload videos that Luke created to the drafts of his own TikTok account. It requests only the video.upload permission.

What is stored

The TikTok access token is stored on Luke's own computer, in the Windows Credential Manager. Nothing is stored on any server run by this tool.

What is shared

No personal data is collected from other people, sold, shared with third parties or used for advertising. Videos are sent only to TikTok.

Revoking access

Access can be removed at any time in TikTok under Settings and privacy, Security & permissions, Apps and services.
